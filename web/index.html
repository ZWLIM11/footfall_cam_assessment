How tracking works
  1. Find badge matches. The detector looks for moving regions in the overhead view and compares patches inside them with the badge pack. Strong, consistent matches anchor a staff track.
  2. Follow the motion. Optical flow estimates how pixels move from frame to frame. The detector links foreground regions whose position, motion, and size are consistent between badge sightings. It can also extend a track briefly from a single sighting.
  3. Flag the source of each point. Direct matches use the badge center. Linked points use the moving region’s center. Short gaps use an estimate between surrounding points. Crossings, occlusion, and people standing still can make a track uncertain.

Coverage measures how many frames contain XY points. The counts above group the points by their source. A frame can contain more than one point.
